🚗 Vehicle Recognition and License Plate Detection System
This project is an AI-powered system for vehicle recognition and license plate detection, combining deep learning models for real-time inference.

📌 Features
✅ License Plate Detection – YOLO-based ONNX model to detect and extract license plates from images.
✅ Car Recognition – Vision Transformer (ViT) model trained with Hugging Face Transformers to classify car make, model, and year.
✅ Efficient Inference – ONNX Runtime for optimized performance.
✅ Real-World Applications – Useful for traffic monitoring, automated toll systems, and vehicle authentication.

🛠 Technologies Used
YOLO (for license plate detection)
Vision Transformers (ViT) (for car classification)
Hugging Face Transformers (for training)
ONNX Runtime (for fast inference)
OpenCV & NumPy (for image processing)
